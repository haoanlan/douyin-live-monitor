## 7. 坑（都踩过，按痛度）

1. **后端必须用系统 TEMP**：TEMP 指向被删的目录时 SQLite 报
   `unable to open database file`。启动前 `$env:TEMP="$env:SystemRoot\Temp"`。
2. **前端构建要隔离 TEMP**：否则 esbuild `Access is denied`。
   `$env:TEMP="<仓库>\.tmp-build"` 再 `node node_modules\vite\bin\vite.js build`。
3. **不要用 PowerShell 双引号 here-string 写 JS/Vue**：
   `` `\``n `` 和 `${...}` 会被 PowerShell 吃掉，上次就因此把文件写坏（字面量 `\n` 出现在代码里）。
   用 `write`/`edit` 工具，或单引号 here-string。
4. **操作列别自造样式**：模板标准写法在 `system/user/index.vue`：
   `fixed:'right'` + `formatter: h('div', { class:'flex-c gap-1' }, [h(ArtButtonTable, …)])`。
5. **ArtTable 的列要能收缩**：给太多 `minWidth` 会让最后一列溢出到卡片边框外。
6. **登录态是内存态**：页面整页刷新会掉登录；自动化测试要重新走登录（拖动验证码）。
7. **Go 代理没有 OnCamRecognition**：实测 `douyinLive-linux-amd64` 里搜不到该字符串。
8. **chrome devtools 里的"未处理消息类型"日志**是排查通道是否到达的最快手段：
   `[roomId] ❓ 未处理消息类型: WebcastXxx`。
