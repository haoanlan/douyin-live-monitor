## 7. 坑（都踩过，按痛度）

1. **后端必须用系统 TEMP**：TEMP 指向被删的目录时 SQLite 报
   `unable to open database file`。启动前 `$env:TEMP="$env:SystemRoot\Temp"`。
2. **前端构建要隔离 TEMP**：否则 esbuild `Access is denied`。
   `$env:TEMP="<仓库>\.tmp-build"` 再 `node node_modules\vite\bin\vite.js build`。
3. **不要用 PowerShell 双引号 here-string 写 JS/Vue**：
   `` `\``n `` 和 `${...}` 会被 PowerShell 吃掉，上次就因此把文件写坏（字面量 `\n` 出现在代码里）。
   用 `write`/`edit` 工具，或单引号 here-string。
4. **操作列别自造样式**：模板标准写法在 `system/user/index.vue`：
   `fixed:'right'` + `formatter: h('div', { class:'flex-c gap-1' }, [h(ArtButtonTable, …)])`。
5. **ArtTable 的列要能收缩**：给太多 `minWidth` 会让最后一列溢出到卡片边框外。
6. **登录态是内存态**：页面整页刷新会掉登录；自动化测试要重新走登录（拖动验证码）。
7. **Go 代理没有 OnCamRecognition**：实测 `douyinLive-linux-amd64` 里搜不到该字符串。
8. **chrome devtools 里的"未处理消息类型"日志**是排查通道是否到达的最快手段：
   `[roomId] ❓ 未处理消息类型: WebcastXxx`。

## C. 新增的坑（都踩过）

9. **Playwright 截图一直失败**：卡在抖音登录页的拖动验证码，3 次尝试全挂；token 注入也没成功（localStorage 键名不是裸 `accessToken`）。

   → 这是 UI 反复返工的根因。

10. **PowerShell here-string 会吃掉反引号和 `${}`**：我写 `@'...'@` 里的 JS 模板字符串时，
    反引号被 PowerShell 解释 → 脚本语法错误 → **一行都没写进去**（发生过 2 次）。
    → 写 Vue/JS 用 `write`/`edit` 工具，别用 pwsh 拼大段代码。

11. **侧边栏不读数据库**：一开始我在 `douyin.ts` 里加了个 `system` 分组，
    但侧边栏只认路由模块 → 出现"两个系统管理"。真正的来源是 `router/modules/account.ts`。

12. **原版模板页已被删除**：`views/system/` 下只剩 `user-manage` / `user-center`。
    要做"和 Art Design Pro 一样的菜单/角色页"，得去 GitHub 拉原版源码：
    `https://raw.githubusercontent.com/Daymychen/art-design-pro/master/src/views/system/{menu,role}/...`
    而 `components/core/{art-search-bar,art-table-header,art-table,art-button-table}` **都还在**，可以直接复用。

13. **`el-table` 插槽的 `row` 类型是 `DefaultRow`**：直接传给 `(row: AdminMenuItem)` 的函数会 tsc 报错 → 处理函数参数放宽成 `any`。

14. **`el-checkbox` 的 `v-model` 不接受数组**：多选用 `el-checkbox-group` 包起来。
